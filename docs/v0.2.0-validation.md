### 网络限制与验证方式

直接搜索实际失败。模拟器系统 DNS 返回的 API 地址与公共加密 DNS 结果不同；宿主经现有代理访问 API 也在 TLS 阶段失败，而海报 CDN 可达。使用加密 DNS 返回地址做匿名 HTTPS 连接对照后正常获得 HTTP 401（无凭据的预期响应）。这证明可达性与解析有关，不将其误报为令牌无效。

随后仅在本次验证期间使用本机临时 CONNECT 隧道让 API 连接使用上述可达地址，TLS 字节原样转发，由应用继续校验证书；未关闭 TLS 校验、未修改应用 API 地址、未固化 DNS/IP 或代理到源码、未记录令牌。真实搜索和保存是在这一临时网络条件下通过。**恢复原网络后，其 API 直连故障尚未解决，不能宣称默认网络已可正常搜索。**
