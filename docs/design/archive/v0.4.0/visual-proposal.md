## 设计判断

Seen 是个人已看电影库。用户喜欢 iPhone 原生软件的简约、高级感；本提案选择清晰的大标题、自然的文字层级、克制的蓝色操作、分组表单和稳定的页面结构。海报是唯一大面积彩色内容，界面负责组织它们。

参考 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)、[Typography](https://developer.apple.com/design/human-interface-guidelines/typography)、[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)。这是对本项目的设计取舍；Android 实现仍采用 Compose、系统字体、Android 返回行为与原生日期/时间/文件选择器。图标沿用现有 Material Outlined 系列，触控区至少 48dp。

已检查现有 Theme、LibraryScreen、MovieScreen、EditorScreen、SettingsScreen 与 v0.3 验证日志，并查看 v0.2 历史详情设备截图；历史截图只用于理解布局，不代表当前版本截图。当前主页标题区分三层，详情资料逐行间距较散，设置将凭据、备份与关于全部铺开，是这轮优先处理的问题。

技能检索说明：ui-ux-pro-max 首轮匹配 AI 产品，重试匹配文档站点，均不适合作为 Seen 的整套设计系统，未持久化搜索输出。采用其中匹配的简约风格原则；字体、配色和页面方案由本 brief 与现有产品约定决定。Compose 检索匹配主题与扁平布局规则；分组表单检索及一次重试无匹配，下述表单属于本项目设计建议。

## 视觉规则

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#F2F2F7` | `#000000` | 页面底色 |
| surface | `#FFFFFF` | `#1C1C1E` | 分组区域、弹层 |
| ink | `#1C1C1E` | `#F5F5F7` | 标题、正文 |
| secondary | `#636366` | `#AEAEB2` | 年份、日期、补充说明 |
| action | `#0066CC` | `#409CFF` | 可执行文字、主按钮 |
| danger | `#B3261E` | `#FF6961` | 删除与错误，同时配文字 |

分隔线单独派生为浅色 `#D1D1D6` / 深色 `#38383A`，仅用于分组；必要控件边界与焦点另设满足 3:1 的 token。浅色主按钮白字，深色主按钮黑字，不直接复用前者。

字体使用 Android 系统中英文字体，不打包 SF Pro 或额外下载字体。页面大标题 32/40sp、600 字重；详情片名 26/34sp、600；区块标题 20/28sp、600；正文与表单 16/24sp；海报片名 16/22sp、500；辅助信息 13/20sp。大标题只出现在主页、设置等入口页，编辑页保留紧凑标题。

以 390dp 常规手机为设计基准：左右 20dp，海报列间 16dp，两列各 167dp；垂直区块间 24/32dp，组内 12/16dp。海报 2:3、圆角 8dp；分组 16dp；搜索框与主按钮 12dp。海报下面的文字直接放在页面上，不再套第二层白卡。分组按内容关系使用，避免所有元素都变成同样的圆角卡片。

海报视图使用白色内容底，设置、表单与观看记录分组使用浅灰底配白色 surface。层次由背景与留白表达，默认无投影。蓝色只分配给动作，评分仍为正文颜色；禁用态必须同时禁用语义。

## 页面方案

### 电影库：保留单主页与两种视图

```text
Seen                       搜索  ＋  更多
我的电影
6 部电影
[ 海报 | 时间 ]                 最近观看
海报                海报
片名                片名
年份 / 个人评分     年份 / 个人评分
```

Seen 收为轻量品牌标识，「我的电影」成为唯一大标题。搜索、添加、更多各保留 48dp 触控区；大标题随页面滚动收为紧凑栏，避免固定三层工具栏占用内容空间。海报/时间改为一个分段选择控件，选中有底形与字重，并提供 selected 语义；右侧显示排序入口。时间视图按月份展示每次观看，数量同步改为“次观看”，排序入口隐藏。

主页搜索按需展开，保留本地语义、关闭/清空与无结果状态。草稿入口是一条“继续未完成的编辑”提示行，位于视图切换下方；不覆盖海报。空库显示“还没有电影 / 添加一部看过的电影。”与添加按钮。加载不显示错误的零数量。

保留电影去重、最近观看排序、最新评分不回退、null 不冒充零分。主页不增加推荐、统计横幅或底部导航。

### 电影详情：紧凑资料与明确历史

返回栏下方放 124×186dp 海报与片名、原名、年份；导演/片长/国家按内容自然换行，不给每个字段独立大段间距。较长资料移到主区下方，全量可读；TMDB 署名保留独立入口。海报不加模糊背景或滤镜。

一个全宽“再看一次”主动作，下方为“观看记录”与次数。每条记录先看日期、个人评分，再看时间/地点，更多操作属于这一次观看。感受只在存在时提供展开入口；无感受不留空卡。已有长感受完整可选中复制。从时间视图进入继续定位并展开相应记录。删除范围与原确认语义一致。

### 添加 / 编辑观看：像一张简洁的原生表单

紧凑顶栏返回、标题、保存；下方小海报与片名建立电影语境。日期与评分放入一个分组，日期是整行可点的选择项；评分保留加减半星与清除，明确显示“未评分”。“时间与地点”“添加感受（可选）”分别按需展开；编辑已有内容时自动展开。

手动建片仍保留片名必填、原名/年份/海报可选，完整错误提示与 Unicode 上限，使用同一分组表单规范。多行输入有持续可见标签；错误紧邻字段，保存失败保留输入。保存动作始终可达，键盘与系统手势区留足 inset。

### 添加电影：搜索与手动入口有主次

搜索框明确“搜索片名或原名”，下方保留显式“搜索 TMDB”按钮，沿用当前提交查询语义；本版不加入自动搜索/防抖逻辑变更。手动添加始终可达。结果为海报、小标题、原名和年份的平整列表，替换当前每项描边按钮；已存电影与 TMDB 结果分别有文字组头，已存结果可再次记录。

不显示社区评分。缺凭据、网络失败、加载中、无结果使用不同文案；错误保留查询与手动入口。分页继续使用清晰的上一页/下一页动作。搜索结果缩略图如果需要新增远端加载逻辑则推迟，先使用中性占位；不把该项变成改版前提。

### 设置：先看分组，再进入具体工具

入口大标题“设置”，三组为“数据”“电影资料”“关于”。数据组显示“备份与恢复”；电影资料组显示 TMDB 凭据配置状态；关于组保留版本与来源署名。长凭据表单与备份详情移至对应子页，继承现有保存/移除、导出/预检/覆盖确认流程。返回设置或电影库时保留来源位置。

备份恢复的明文说明、未完成编辑限制、预检统计、覆盖范围、确认与失败提示完整保留，不为视觉简洁删掉关键确认。TMDB 官方 logo 与完整免责声明保留在电影资料子页；设计总览仅展示入口层。

## 浅深色与动效

建议 v0.4 范围包含跟随系统的浅/深色主题；暂不新增三态偏好开关，减少设置与持久化改动。深色独立配置颜色并移除 `Color.White` 等硬编码。附图仅提供深色主页参考，其他深色页面须在实现阶段逐页验收。

按下反馈 80–150ms；分段切换 150–180ms；可选内容展开 180–220ms。遵从系统动画比例；减少动态效果时直接呈现终态。大标题收起不引入弹跳、视差与海报自动播放。当前阶段不引入磨砂或 Liquid Glass 效果。

## 实施顺序与边界

1. 建立 Theme 色彩、Typography、间距、圆角与公共分组/分段控件；更新 Preview，覆盖浅深色。
2. 调整主页海报/时间视图、搜索、草稿与空状态；核对相同数据下排序与数量一致。
3. 收敛详情信息层级，统一观看记录与表单；保留定位、保存、草稿与退出行为。
4. 调整添加电影列表及设置子页；回归备份全流程与凭据状态。
5. 完成构建、API 36、截图与真机人工验收，再按版本约定决定交付。

保持单 app 模块、手动注入和现有架构；无需新增依赖、数据库 schema 或备份协议。新增设置子页使用现有导航模式。若实现发现需要修改业务或协议，应单独说明原因和范围；视觉提案不授权发布、推送或打 tag。

## 实现后的验收门槛

- `bash scripts/check.sh`：编译 App/测试 APK、JVM 测试、lint；业务规则如有变化增加对应验证。
- 在明确选择的隔离 API 36 设备执行 `ANDROID_SERIAL=… bash scripts/check.sh --device`；覆盖新增/编辑/重看/删除、草稿/返回位置、搜索失败、主题切换、设置子页及备份恢复，不能触碰真实实例。
- 约 360/390dp 手机、窄屏、大屏与横屏；100%/200% 字号；键盘打开；浅深色独立截图。极窄屏或大字号海报退为单列，详情改上下布局，分段与排序必要时分行。
- TalkBack 名称、角色、选中/展开/忙碌状态、焦点顺序、错误与恢复结果播报；Android 最小触控区 48dp；普通文字对比度至少 4.5:1，必要图标/控件至少 3:1。
- 关闭系统动画检查交互可完成；完整感受、长片名、中文/emoji、无海报、未评分/未知时间、空库/大库均可读。
- Redmi 真机人工观察单列；完成实现后新建版本验证日志，记录命令、最终源码/APK 哈希、报告路径和限制。
