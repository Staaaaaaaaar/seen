# 开发规划

当前交付版本为 **v0.1.0**；每版完成后暂停，不自动进入下一版。实际执行结果见 [验证日志](v0.1.0-validation.md)，提交、CI 与 tag 的交付顺序见 [发布约定](versioning.md)。

## 版本范围

| 版本 | 范围 | 主要验收条件 |
| --- | --- | --- |
| v0.1.0 | 离线电影主页、海报/时间视图、本地搜索、电影详情、手动建片与本地海报、观看增删改查、重复观看、可选半星评分/感受、草稿与 Room 持久化；稳定开发环境与 CI | 构建/单测/lint、API 36 自动化通过；离线与重启可用；主页按电影去重，时间视图保留每次观看；保存失败保留输入；IDE 同步与 Preview 可用 |
| v0.2.0 | TMDB 搜索、电影资料与署名、持久海报、手动补录与网络容错 | 中文/原名与同名年份可区分；无凭据、断网、超时仍可手动记录；保存后离线可读；TMDB ID 复用；从 v0.1 升级不丢数据 |
| v0.3.0 | JSON 导出、导入预检与安全覆盖恢复、迁移和边界质量 | 隔离实例恢复后字段/ID/海报一致；损坏引用、高版本、超限或写入失败不改原库；真实旧库迁移、长中文/emoji/null、TalkBack/200% 字号/窄屏回归 |
| v1.0.0 | 真机回归、Release 签名、升级验证、维护文档与正式私人发布 | 相同包名/签名覆盖安装保留数据；签名指纹、APK SHA-256、CHANGELOG 和升级说明可核对；正式 GitHub Release |

电影主页与详情已从原 v0.2 前移至 v0.1，本地海报也属于 v0.1；联网仍在 v0.2。备份草案见 [产品与设计](design-review.md)。不增加社交、推荐流、广告、影视播放或云同步。

- [GitHub Actions](https://github.com/Staaaaaaaaar/seen/actions/workflows/android.yml)：最终 tag 对应提交的顺序工作流中，构建/单测/lint 与 API 36 测试均须成功。

当前不新增框架或拆分模块，不因下载故障自动升降依赖版本。后续每版交付应包含实际变更、测试结果、APK 路径/校验和、设备记录与限制。
