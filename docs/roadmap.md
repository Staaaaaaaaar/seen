## 维护边界

保持单 app 模块、Kotlin/Compose、ViewModel → Repository → Room 与手动依赖注入。数据库变化须显式迁移并保留历史 schema；电影和观看分别存储，null 评分/时间语义不改变。保存失败保留输入，设备测试使用隔离合成数据。

后续维护聚焦可复现缺陷、备份兼容、工具链与依赖维护。正式版覆盖安装必须保持包名与签名；长期密钥在仓库外保管。任何新阶段产品范围、架构调整或数据协议变化需先确定范围和验收条件。

## v1.1.0：简单片单（历史实现）

底部为记录、片单、设置，记录页提供添加入口。片单仅以列表保存想看电影，不增加集合/分组。支持手动和 TMDB 添加、移出及记录观看；新观看保存成功后事务移出，取消或失败不移出。已有观看电影可加入片单以表达重看。Room v2 从 v1 显式迁移；备份扩展为可选 `wantToWatch`。验证见 [日志](v1.1.0-validation.md)。

## 统一影库改版（本轮，本地验收）

已授权用影库、统计两栏替代旧片单导航；电影可独立添加，已看只由观看记录推导，评分独立于观看，普通留言不增加次数。详情采用海报主体、宋体标题与蓝灰主题，补充简介和演职人员。统计仅为数量、月频率、类型；资料语言支持 zh-CN / en-US，全库准备完成后原子切换。

Room v3 显式保留 v1/v2 迁移链，备份协议 v2 兼容 v1。旧每次观看评分保留，初始个人评分取原界面最新观看的值，包括 null；旧海报保留归档引用。旧待看字段作为兼容数据保存，不再决定页面状态。

本轮不新增账号、社交、推荐、播放或云同步；不擅自改版本号、发布或沿用历史推送授权。实际验证和限制见 [本轮日志](library-redesign-validation.md)。

## 界面反馈调整（2026-11-07）

按用户实际查看后的反馈，排序方向移至每项右侧上下箭头，筛选和排序共用中心线与居中的点击区域；统计固定全部历史数据，两页共用影库字标。演职人员完整横向浏览，取消展开，导演归入该区，类型旁取消重复观看数量。新建影片仅搜索，移除手动选择；来源在设置说明。历史手动影片和草稿继续兼容，不删除既有数据。最新证据见 [反馈验收记录](ui-refinement-validation.md)。
