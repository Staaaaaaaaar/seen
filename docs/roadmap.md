# 开发规划

当前版本为 **v0.4.0**，底栏与海报电影库、记录流程、设置及视觉调整已完成本地验证；用户已授权提交、推送与 annotated tag。实际交付状态以远端记录为准，证据见 [v0.4 验证日志](v0.4.0-validation.md)。每版完成后暂停，不自动进入下一版；交付按 [发布约定](versioning.md)。

电影主页与详情已从原 v0.2 前移至 v0.1，本地海报也属于 v0.1；联网仍在 v0.2。备份草案见 [产品与设计](design-review.md)。不增加社交、推荐流、广告、影视播放或云同步。

## v0.4 界面实现

底部为电影库、添加记录、设置；电影库统一海报，详情保留全部观看历史。顶部收敛为紧凑页名、搜索和排序；记录流程与设置工具页已实现，支持系统浅深色。

当前约定见 [产品与设计](design-review.md)，布局依据见 [第三稿](v0.4.0-navigation-design.md)，实际执行与人工待验收见 [验证日志](v0.4.0-validation.md)。前两稿移入 [设计归档](design/README.md)，不再作为实施依据。本版不扩展社交、推荐、播放或云同步。

远端交付使用可直接核对的记录，避免在源码中维护“本提交已完成 CI”的自指状态：

- [GitHub Actions](https://github.com/Staaaaaaaaar/seen/actions/workflows/android.yml)：最终 tag 对应提交的基础 CI（App/测试 APK 编译、JVM 单测、lint）须成功；云模拟器不作为强制门槛，本地 API 36 设备验收另有真实记录。
- [版本 tag](https://github.com/Staaaaaaaaar/seen/tags)：`v0.1.0` 使用 annotated tag，远端 peeled commit 须与已验证提交一致。

当前不新增框架或拆分模块，不因下载故障自动升降依赖版本。后续每版交付应包含实际变更、测试结果、APK 路径/校验和、设备记录与限制。

## v0.2 功能范围

已接入 TMDB 搜索/分页、中文与原名及年份辨识、详情字段持久化、私有海报、设置中的可移除访问凭据与官方署名。无凭据、超时和网络错误保留手动入口；重复 TMDB ID 在事务内复用电影。数据库沿用 v1 预留字段，历史 schema 保留，无结构迁移。

实际验证与未完成验收见 [v0.2 日志](v0.2.0-validation.md)；v0.2 本地功能验收已完成，交付状态以远端记录为准；当前已按授权进入 v0.3，进展见 [v0.3 日志](v0.3.0-validation.md)。
