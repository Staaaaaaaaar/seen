# 开发规划

第一阶段以 **v1.0.0** 收束：个人本地电影库、每次观看历史、可选 TMDB 资料、JSON 备份、系统浅深色与正式签名发布。验收与限制见 [v1.0 验证日志](v1.0.0-validation.md)，安装和调试版迁移见 [发布流程](release.md)。后续阶段需另行授权，不自动增加推荐、社交、影视播放或云同步。

## 维护边界

保持单 app 模块、Kotlin/Compose、ViewModel → Repository → Room 与手动依赖注入。数据库变化须显式迁移并保留历史 schema；电影和观看分别存储，null 评分/时间语义不改变。保存失败保留输入，设备测试使用隔离合成数据。

后续维护聚焦可复现缺陷、备份兼容、工具链与依赖维护。正式版覆盖安装必须保持包名与签名；长期密钥在仓库外保管。任何新阶段产品范围、架构调整或数据协议变化需先确定范围和验收条件。
