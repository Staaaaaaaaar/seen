# 电影详情中的资料更新

用户最新要求将入口移到每部电影详情页右上角。本设计据此调整为对当前电影完整更新，用于补齐旧备份缺少的演员、类别等资料，并重试网络超时后的拉取。

## 方案

复用现有 MetadataRefreshCoordinator，增加按电影 ID 更新的能力，在详情页右上角已有电影操作菜单中加入「更新资料」。更新当前电影的完整资料；相比只补缺失字段，也能修正已有的不完整内容。设置不增加入口。

## 行为

- 每次手动开始后重新请求当前电影的完整资料，固定简体中文；无 TMDB ID 的历史手动电影不提供更新操作。
- 更新电影基本资料、简介、类别、演职人员和默认海报；保留电影 ID、创建时间、独立评分、全部观看和留言，保留历史归档海报。
- 详情页的更新对话框说明需要访问凭据和网络，显示进行中、完成、失败或中断状态，提供开始、取消及失败后重新更新的入口。未配置凭据时明确提示先在设置配置。
- 沿用现有事务：当前电影的资料和海报全部准备完成后统一生效；拉取失败则保留原资料。重新点击时重新拉取当前电影，不提供断点续传或自动重试。
- 准备过程中避免重复任务；沿用资料更新与导入、增删影片、凭据修改之间的互斥，开始前处理未完成编辑和启动恢复。
- 不新增依赖、数据库迁移或语言选项，不改个人数据。

## 交付和验证

修改详情页面、ViewModel 入口、资料更新协调器及相关说明。先交付代码；未经用户进一步指令，不运行构建、check、测试或模拟器安装。待手动验收覆盖成功、超时失败后重试、取消、无凭据、空候选和个人记录保留。
