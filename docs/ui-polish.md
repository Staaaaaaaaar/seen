# 界面细化与手动验收

本文件说明当前统一影库的最终界面行为；此前版本的测试结果仅属于各自验证日志，不能作为本轮通过证明。界面细化本身不改变数据库结构或备份格式版本。后续1.2.0版本验收见[版本日志](v1.2.0-validation.md)。

## 影库与设置

影库、统计共用顶栏，统一字标位置与设置图标尺寸。影库筛选、排序和列表共用24dp内容边线，选项栏上下各4dp留白。排序依据与方向为独立控件，取消添加时间排序；切换依据或方向均回到列表顶部。

电影行左侧为约64×96dp海报，右侧片名与海报顶部对齐，年份和类型组成一组贴近底部，评分居中。海报与文字区随系统字号增高，年份与类型间距4dp。取消星星和观看次数；未评分横线与评分数字位置相同。右下角添加按钮为圆形。

搜索和新电影资料固定简体中文；设置移除语言切换与批量更新入口。移除旧页面后，恢复的旧导航栈退回设置。历史语言字段、草稿、海报与备份继续兼容，底层中断恢复保留，不因本次清理删除数据。

## 详情与记录

观看使用细线眼睛标记，与影库场记板区分。人物卡片、图片、姓名与角色统一72dp宽度，姓名和角色最多两行，横向浏览与人物详情保留。

简介超过四行、记录正文超过五行时折叠，点击文字展开或收起，不再显示箭头按钮，长按仍可选择文字。正文使用15sp衬线、26sp行高。记录顺序为日期时间、正文、地点，共用左边线；菜单保留48dp触控范围，可见图形与日期靠近行底对齐，正文与地点间距10dp。记录之间保留细分隔线，末条不绘制尾线。

日期、时间使用 Android 原生选择器，固定输出 yyyy-MM-dd 和24小时 HH:mm；时间可选择不记录，空时间与00:00含义不同。取消选择不修改输入。

评分独立于观看，支持0–5分、半星和未评分；点选已选分值归零，长按星星清除，读屏提供清除评分操作。输入、Repository和备份校验均接受零分。

## 统计

数量汇总固定全部历史；两个总数各自居中，单位置于下方。近期观看展示含本月的最近六个自然月，保留零值、不展示未来月份，横轴只显示月份，跨年也不增加年份标注。

类型环图展示数量最高四类，其余合并为其他；多个类型按类型归属次数分配扇区，同一电影可以贡献多个类型。环图连续无间隙，中心不显示标题；下方图例为三列等宽网格，仅色点与名称，不显示数字。无记录时保留空环与提示。

最近一次用户要求的模拟器更新已完成离线 assembleDebug、覆盖安装和启动，包含圆形添加按钮及留言排版。没有运行 check、lint、JVM或设备测试；测试源码更新不代表已通过。

本次仓库整理仅移除无调用的资料更新入口方法、无用导入和生成物，合并过程说明；整理后未重新构建或测试。构建目录中的历史报告已归档到仓库外临时目录，原历史验收结论保持其原有范围。

模拟器含原有记录和用户授权添加的虚构演示数据，已正常关闭并保留数据。数据、海报、凭据和本机配置均不进入提交。后续设备测试必须使用隔离设备，不能在个人记录实例中运行。
