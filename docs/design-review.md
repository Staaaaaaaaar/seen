# 产品与设计约定

当前适用于 v0.4.0。Seen 是个人已看电影库，Movie 是浏览主体，每次观看 Viewing 独立保存。用户已查看模拟器并授权交付；功能实现不等于真机与读屏验收全部完成，实际证据见 [验证日志](v0.4.0-validation.md)。

[第三稿布局与流程](v0.4.0-navigation-design.md) · [四屏静态稿](design/v0.4.0-layout-v3.png) · [历史设计归档](design/README.md)

## 数据与产品边界

- 个人、单设备、本地优先，无 Seen 账号、广告、遥测、推荐流、播放或云同步。
- 电影库按电影去重；一部电影可有多次观看，详情保留全部历史。删除一次不影响其他观看；最后一次删除后主页隐藏电影，保留 Movie 供复用。
- 个人评分属于某次观看，0.5–5 星、半星步进、可不评分。主页使用最近一次观看的评分，不回退旧评分或取平均；null 不等于最低分。
- 观看日期为 LocalDate，时间可空；不把未知时间替换成 00:00。创建/更新时间使用 UTC Instant。
- 新电影与首次观看在最终保存事务中创建，步骤切换不落库。稳定 ID 防重试重复；同 TMDB ID 复用，同名手动电影不自动合并。
- 海报导入后复制到私有存储；草稿私有暂存，失败保留输入。Unicode 按码点检查：片名/原名 300、地点 200、感受 50,000；数据迁移禁止清库。

## 页面职责与导航

| 页面 | 内容与动作 | 底栏 |
| --- | --- | --- |
| 电影库 | 海报网格、本地搜索、排序；点击进入电影详情 | 电影库选中 |
| 选择电影 | 本地匹配优先、显式 TMDB 搜索、手动添加 | 隐藏 |
| 电影资料 / 添加观看 | 手动资料与观看两步；日期必填，其余可选 | 隐藏 |
| 电影详情 | 紧凑资料、全部观看、再看一次、编辑/删除本次观看、感受展开 | 隐藏 |
| 设置 | 凭证、导出、导入、关于四个入口 | 设置选中 |
| 设置工具页 | 各自凭证/数据流程、来源与免责声明 | 隐藏 |

底部左侧电影库、中间添加记录、右侧设置。中间是新增按钮，不建立空白 Tab。根页切换保留状态；设置系统返回电影库，电影库根页采用 Android 默认返回行为。选片取消回来源；保存成功进入电影详情并定位/展开本次观看，再返回电影库保留搜索、排序和滚动。

编辑有修改时退出需明确放弃；手动观看步骤返回资料步骤，输入保留。已有草稿时新增提供继续、放弃后新建、取消。写入或恢复预览期间不能绕过已有保护。

## 电影库与电影详情

电影库顶部只显示紧凑“电影库”及搜索、排序；不再重复 Seen 品牌、大标题、数量行和海报/时间切换。数量位于排序菜单；默认最近观看，支持片名/年份排序。本地搜索只查片名与原名，不与 TMDB 结果混合。

390dp 基准两列、左右 20dp、列间 16dp；海报 2:3、圆角 8dp。片名最多两行，辅助信息弱化，重看时显示次数；不在主页放感受或地点。窄于 350dp 或字体比例至少 1.5 时改为单列，宽屏最多五列。缺图保留稳定海报比例与可读片名，列表滚动范围计入底栏及手势区。

详情先识别电影，再进入个人历史；资料紧凑排列，更多资料按需展开，TMDB 来源可找到。观看记录按日期/时间/创建时间与 ID 稳定倒序；“再看一次”在历史标题旁，窄屏可换行。详情右上角“电影操作 → 删除电影”作用于整部电影，确认框明确片名及全部观看次数；确认后事务删除电影与其观看记录并返回电影库，可重新搜索导入，取消不改数据。记录菜单作用域仅本次观看；感受支持短摘录、展开全文及复制，无感受时不显示空卡。

## 记录与设置流程

选择电影先显示本机匹配，远端通过搜索按钮或键盘搜索显式提交。缺凭证、超时、断网、无结果分别提示，保留查询与手动入口。远端结果不额外引入缩略图下载；选择后获取资料与私有海报，失败不阻止手动记录。

手动建片先填片名及可选原名/年份/海报，下一步进入本次观看。日期默认今天，禁止未来日期；评分可清除，时间/地点与感受按需展开。TMDB 新电影可纠正资料并选择本地海报；本版不增加已有 Movie 的资料编辑。保存抑制连击，失败不丢输入，错误靠近对应字段；资料错误返回资料步骤处理。

设置直接提供 TMDB 凭证、导出数据、导入备份和关于。凭证只保存在本机私有存储，不进入备份或 Activity 状态；保留移除、获取链接和 TMDB 官方署名。

导入导出使用系统文件选择器。导出先准备并校验，备份为明文；恢复先预检统计再确认覆盖，不合并，保留先导出现有数据、取消、错误与结果播报。未完成草稿阻止恢复。完整协议与限制以 [备份格式](backup-format.md) 为准。

## 视觉与无障碍

海报提供主要色彩，其余界面使用中性背景、深墨色操作、轻分隔线；不使用大面积磨砂、渐变或统一投影卡片。系统字体贯穿中英文；浅深色跟随系统，系统栏同步。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 / surface | `#FAFAF9` | `#141516` |
| 主文字 / primary | `#202124` | `#F0F0EE` |
| 辅助文字 | `#64676C` | `#B0B2B6` |
| surfaceVariant | `#EEEFEF` | `#282A2C` |
| 分隔线 | `#DDDFE1` | `#393C40` |
| 错误文字 | `#A63732` | `#FFB4AB` |

页面标题 22/30sp、详情标题 26/34sp、区块标题 17/25sp、正文 16/26sp、辅助文字 13/20sp。间距采用 4dp 倍数；所有操作至少 48dp 触控区。窄屏大字号中央文案缩为“记录”，读屏名称仍为“添加记录”；编辑页使用较紧凑标题。

图标统一 Material Outlined，装饰图标不重复播报，按钮具名称、状态与按下反馈；返回、错误和焦点不依赖颜色。无自动播放或非必要入场动画。窄屏、200% 字号、横屏与关闭动画已做核心流程验证，TalkBack 朗读/焦点和 Redmi 真机体验仍按验证日志单列待验收。
