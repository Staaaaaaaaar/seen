# Seen Serif 字体

本应用离线打包 Seen Serif，基于 Adobe / Google 的 Noto Serif CJK SC Regular，采用 SIL Open Font License 1.1。完整许可见 [seen-serif-OFL.txt](seen-serif-OFL.txt)。

上游项目：https://github.com/notofonts/noto-cjk/tree/main/Serif

资源为简体中文 GB2312 常用字、应用文字、拉丁字符及常用标点子集；通过 fontTools 从 Noto Serif CJK Regular 简体中文字体生成，并更名为 Seen Serif，以遵守保留字体名称要求。未覆盖的字符由 Android 系统字体回退。字体资源无需联网下载，许可允许随应用分发；不单独销售字体。
