## 范围

底部为记录、片单、设置；添加记录移至记录页右下角。片单以列表展示海报、片名和年份，可手动/TMDB 添加、移出、记录观看，不提供小集合。想看状态独立于观看历史；新观看事务保存成功后移出，取消和失败保留；编辑旧观看不移出。移出片单保留电影资料与历史。

Room v1 → v2 显式新增默认 false 的 `wantToWatch`，保留历史 schema。草稿保存片单意图，旧草稿默认观看；备份可选字段兼容旧备份，旧版应用恢复会忽略想看状态。
