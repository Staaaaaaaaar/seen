## 实现

- 搜索、分页和详情共用 API 传输策略。首次优先使用 `api.tmdb.org`，网络 IOException 失败后最多尝试一次原入口 `api.themoviedb.org`；成功后在本进程复用该入口，避免后续重复请求不可达域名。
- 回退地址只允许 `https://api.themoviedb.org` 和 `https://api.tmdb.org`。不接受任意用户 URL、不固定 IP、不改变系统 DNS/代理、不关闭证书校验、不跟随重定向。
- 鉴权/权限/限流等 HTTP 错误、TLS 错误、解析/响应大小错误不回退；协程已取消时不继续启动第二次请求。
- DNS、TLS、超时和普通网络错误分别显示固定中文提示，不包含访问令牌。海报保持原 CDN，无 API Bearer header。
- 版本 0.2.1 / versionCode 3，包名与签名沿用。正常情况下直接连接已在用户网络可达的 `api.tmdb.org`；成功入口只缓存在本次进程，不承诺所有网络都可达。
