## 最终实现

- 海报请求使用 `Accept: image/*`；连接类 IOException 延迟 300ms 后仅重试一次。TLS、HTTP、超限和取消不重试；不更换 CDN 或绕过证书校验，海报不携带凭据。提示区分超时、域名解析、安全连接、连接和图片读取/保存失败。
- 电影详情右上角“电影操作 → 删除电影”。确认框显示片名、全部观看次数及不可撤销提示；取消不改数据，确认后事务删除电影及其全部观看记录，返回电影库，可重新搜索相同 TMDB ID 并导入。
- 沿用 LibraryAccess 写入协调与 Room 事务，删除失败回滚，其他电影不变。备份恢复预检期间拒绝写入；有该电影未完成编辑时先保存或放弃。
- 沿用海报延迟回收策略，不提前删除可能被草稿/快照引用的文件。Room v1 / 历史 schema、备份格式、依赖和包名保持不变。

## 排查证据与限制

电脑 `curl --noproxy '*'` 实际请求官方海报 CDN 返回 HTTP 200、image/jpeg、90522 字节；隔离 API 36 临时真实联网探针完成下载、私有保存与解码，1 项通过，日志 `.tools/poster-live-probe.log`。探针已移除，普通测试使用合成图片和固定响应，不依赖外网。原 JSON Accept 在电脑也能成功下载，因此请求头修正不作为真机故障根因；用户确认偶发恢复也不等同于完成修复包真机验收。

此前 0.4.0 源码候选已通过 24 项 JVM、38 项 API 36。覆盖首次连接失败恢复、持续失败最多两次、TLS/HTTP/校验不重试、取消、私有媒体；删除确认取消/旋转、两次观看及整片删除、保留其他电影、同 TMDB ID 重新导入、恢复互斥和强制数据库失败回滚。首次新增测试遗漏清理合成库，导致旧空库测试超时，补充 After 清理后已完整通过，未跳过旧测试。该候选证据不替代下述 v0.4.1 打包检查。

本轮设备测试仅使用隔离数据库/文件/偏好，没有删除真机记录。TalkBack 实际朗读、真机网络、真实旧 APK 覆盖升级和签名 Release 未在本补丁执行；v0.4 界面专项历史见 [v0.4 日志](v0.4.0-validation.md)。
