# 温暖杂志风与页面节奏调整

根据用户提供的根目录概念展板，只提取视觉氛围，保留影库/统计结构。使用 frontend-design 与 ui-ux-pro-max；杂志风格检索匹配 editorial-grid-magazine，原生实现使用 Compose Arrangement/Alignment，不套用检索中的网页营销模板。

## 设计规则

浅色：纸色 #F6F0E7、墨色 #302A24、辅助字 #716353、暖棕 #785638、分隔 #D9CDBD、底栏 #F0E7DB。深色对应暖墨 #231F1B、正文 #F2E8DB、辅助字 #C6B5A2 与浅棕 #D4B28C。沿用离线中文衬线字体与清晰的无衬线元数据。

采用 8dp 间距体系与 16/24/32/40dp 层级；统计顶部留 32dp，模块间 40dp；影库顶栏与选项栏、选项栏与内容各留 16dp。没有适用于所有页面的固定黄金分割，本轮按阅读顺序和原生触控尺寸分配比例。

海报 76×114dp，列表以片名、年份、类型和数字评分组成，不显示星形和观看次数。导航/观看标记使用同一细线场记板。排序入口呈现当前方向箭头，取消添加时间选项，旧显示偏好映射到片名排序。

空状态统一衬线标题、受限宽度、居中对齐与留白。空库月度统计保留当年十二个月零值图表；类型显示无记录，不展示注脚。评分取消右侧叉号，再次点选相同星值可清除，读屏保留清除操作。

本轮不改数据库与备份协议。最终构建、设备回归与截图核对结果在执行后补充；真实手机/联网/TalkBack 人工体验仍需另行验收。
