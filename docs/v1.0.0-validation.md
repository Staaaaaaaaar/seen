## 人工与环境边界

本轮自动化只使用隔离 API 36 和合成数据；用户此前真机体验不等于本轮 v1.0 真机覆盖升级、TalkBack 和系统图片提供器全面验收。真实 TMDB 网络依赖用户网络/凭据，固定响应测试不能替代真实网络。标准 Studio/Gradle 流程保留，macOS/Windows 未在本轮实测。具体未验项随最终结果列出，不伪称通过。
