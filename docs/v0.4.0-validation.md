# v0.4.0 开发与验证日志

2026-10-25：用户已授权按第三稿实现，并允许调整视觉效果。版本 0.4.0 / versionCode 5；用户已在模拟器查看后授权整理、提交、推送和 annotated tag；实际远端状态以 Actions 和 tag 为准。设计依据见 [底栏与海报电影库方案](v0.4.0-navigation-design.md)。

## 实现范围

- 根页面底栏：电影库、添加记录、设置。添加是按钮而非空白 Tab；详情、选片、编辑及设置工具页隐藏底栏。设置返回电影库，选片取消返回来源。
- 电影库仅海报网格，移除品牌/重复标题/数量行/视图切换，顶部仅页名、搜索和排序。数量在排序菜单中；保留本地查询、排序、滚动与大字号单列适配。历史时间偏好不再读取或改写。
- 选片优先本地匹配，远端显式搜索与手动入口仍可用。TMDB 结果改为普通列表，不新增远端缩略图下载；原有 TMDB ID 复用保留。
- 手动电影资料与本次观看分两步；返回/旋转保留输入，最终保存才建片。TMDB 新电影可修改资料和选择本地海报，资料错误自动回到可纠正字段。已有电影不在本版增加资料编辑能力。
- 有草稿时新增需继续、明确放弃后新建或取消；保存后电影详情定位/展开此次记录，补记较早日期也可见。详情资料区收紧，观看记录使用平整布局，感受支持三行摘录及展开复制。
- 设置直接展示凭证、导出数据、导入备份、关于；工具页保留明文范围说明、草稿限制、预检统计、明确覆盖、先导出、取消、错误与结果播报。来源 logo 与完整免责声明保留。
- 中性浅底/深墨色操作、明确系统字体层级、轻分隔线与统一圆角；系统浅深色与系统栏同步。Android 最小触控区 48dp；日期为可点表单行，评分仍半星步进且可清除为 null。
- Room v1 / 历史 schema、备份协议、包名、手动注入与依赖版本均不变。
